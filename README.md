# NOIRE
 
A fashion website concept (NOIRE) built step by step over a 5-week frontend internship. Each folder is one week's task, standalone and independently submitted.
 
## Folders
 
| Folder | Task | Tech |
|---|---|---|
| `NOIRE_Task1_Submission` | Static webpage from a wireframe | HTML, CSS |
| `NOIRE_Week2_Submission` | Responsive design | HTML, CSS (media queries, fluid images) |
| `NOIRE_Week3_Submission` | Interactive UI | HTML, CSS, JavaScript |
| `NOIRE_Week4_Submission` | Performance & accessibility audit | HTML, CSS, JS (optimized build) |
| `NOIRE_Week5_Submission` | Single Page Application | HTML, CSS, JS (client-side routing) |
 
Each folder has its own `index.html` — open it directly, or run a local server where noted below.
 
## Reports
 
`NOIRE_Week1_Report.docx` to `NOIRE_Week5_Report.docx` — one report per week, explaining what was built, design decisions, and challenges faced.
 
## How to run
 
- **Task 1, Week 2, Week 3:** open `index.html` in a browser directly.
- **Week 4:** open `dist/index.html`, or run:
```
  cd NOIRE_Week4_Submission
  npm install
  npm run serve
```
- **Week 5 (SPA):** needs a local server (uses JavaScript modules and routing):
```
  cd NOIRE_Week5_Submission
  npm install
  npm run dev
```
 
## Notes
 
- No backend — this is a frontend-only demo. No real orders are placed.
- Images are cropped from a Figma prototype screen recording, so resolution is limited.
- Built as part of a Frontend Web Developer internship, Weeks 1–5.
